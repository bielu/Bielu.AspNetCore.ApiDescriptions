New package `Bielu.AspNetCore.Arazzo.Scalar.Aspire` renders Arazzo workflows in a .NET Aspire AppHost's Scalar resource. `WithArazzo()` loads the `@bielu/scalar-arazzo` plugin (pinned on jsDelivr) through Scalar's `PluginUrls`, and `AddArazzoDocument()` adds the documents `MapArazzo()` serves as sources of an API reference, next to its OpenAPI and AsyncAPI documents.
