Add `Bielu.AspNetCore.ApiDescriptions.Mcp`, a new experimental package (diagnostic `BIELUMCP001`) that lets AI agents build integrations from an app's own API descriptions through a Model Context Protocol server. `IMcpServerBuilder.WithApiDescriptions()` exposes every AsyncAPI, OpenAPI and Arazzo document the app serves as the resource template `apidescription://{kind}/{name}`, plus six read-only tools. `list_api_descriptions` lists the documents with their titles, specification versions and the tools that can inspect each. `find_api_operations` searches AsyncAPI operations across documents and returns a handle for each match. `get_api_operation` returns one operation's complete documented contract: channel, servers, security, messages and schemas, bindings, reply and examples, with references keyed by canonical JSON Pointer and what the document does not specify listed. These three return `structuredContent` with an `outputSchema`. `get_api_description`, `list_asyncapi_operations` and `get_asyncapi_message` return a whole document, an operation summary and one message with its references. Messages are identified by canonical pointer, so aliases and inline messages resolve. The documents are written as build-time generation writes them, overlays included. The package is built on the official `ModelContextProtocol` C# SDK 2.3, and the SignalR chat example serves it at `/mcp`.
