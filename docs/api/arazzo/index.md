# API Documentation

Welcome to the Bielu.Arazzo.NET API documentation. This section contains the technical reference for
the Arazzo spec library.

## Main Components

- **Bielu.Arazzo.NET**: The object model, JSON/YAML writers, runtime-expression parser, and validator
  for the Arazzo Specification. Framework-free — no ASP.NET dependency.
- **Bielu.Arazzo.NET.Readers**: JSON and YAML readers that parse Arazzo documents into the model above,
  with diagnostics rather than exceptions.
