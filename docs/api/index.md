# API Reference

Bielu API Descriptions is split into two libraries, each with its own API reference:

- [AsyncAPI →](asyncapi/index.md) — `Bielu.AspNetCore.AsyncApi` and related packages for generating
  AsyncAPI documents from ASP.NET Core APIs.
- [Arazzo →](arazzo/index.md) — `Bielu.Arazzo.NET` and `Bielu.Arazzo.NET.Readers`, the object model and
  readers for the Arazzo Specification.
