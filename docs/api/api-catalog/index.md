# API Documentation

Welcome to the Bielu.AspNetCore.ApiCatalog API documentation. This section contains the technical reference for
the API catalog package.

## Main Components

- **Bielu.AspNetCore.ApiCatalog**: `AddApiCatalog`/`MapApiCatalog`, which serve an
  [RFC 9727](https://www.rfc-editor.org/rfc/rfc9727) API catalog at `/.well-known/api-catalog`, listing every
  OpenAPI, AsyncAPI and Arazzo document the app serves as an RFC 9264 Linkset.
