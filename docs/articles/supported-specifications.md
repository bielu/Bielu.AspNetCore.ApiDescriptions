# Supported specifications

This page lists the specification versions each part of the package family reads, validates, or emits. Version
numbers below are the ones the code and the test suites actually cover.

| Specification | Versions | Generated by | Read / validated by |
| --- | --- | --- | --- |
| [AsyncAPI](https://www.asyncapi.com/docs/reference/specification/v3.1.0) | 3.1.0 (default), 2.6.0 | `Bielu.AspNetCore.AsyncApi` | `Bielu.AspNetCore.AsyncApi.Cli`, `Bielu.AspNetCore.AsyncApi.Merger` |
| [Arazzo](https://spec.openapis.org/arazzo/latest.html) | 1.0.x, 1.1.x | `Bielu.AspNetCore.Arazzo` (1.1.0 by default, set with `ArazzoOptions.Version`; also written at [build time](build-time-generation.md#arazzo-documents)) | `Bielu.Arazzo`, `Bielu.Arazzo.Readers`, `Bielu.Arazzo.Cli` |
| [Overlay](https://spec.openapis.org/overlay/latest.html) | 1.0.x, 1.1.x | not generated; applied by `Bielu.Overlay` | `Bielu.Overlay`, `Bielu.Overlay.Readers`, `Bielu.Overlay.Cli` |

## AsyncAPI

`AsyncApiOptions.AsyncApiVersion` selects the output version:

| Option value | Document declares |
| --- | --- |
| `AsyncApiVersion.AsyncApi3_0` (default) | `3.1.0` |
| `AsyncApiVersion.AsyncApi2_0` | `2.6.0` |

Generated documents for both versions are validated against the official AsyncAPI JSON Schemas in the test suite
(`AsyncApiOfficialSchemaConformanceTests`), so output that drifts from the spec fails CI.

Some features only exist in one version of the specification. `reply` on operations, for example, is an AsyncAPI 3.x
concept and has no equivalent in 2.6.0.

Protocol bindings come from `ByteBard.AsyncAPI.NET.Bindings`. In 3.0.1 a few of its bindings produce output that fails
the official 3.1.0 schema. 3.1.0-beta.19 fixes them; see [Broker bindings](protocols-broker-bindings.md).

## Arazzo

The object model, readers, validator, and CLI accept `arazzo: 1.0.x` and `arazzo: 1.1.x`. Following section 5.1 of the
spec, patch versions are not distinguished. Any other value, including `1.10.0`, is rejected.

## Overlay

`Bielu.Overlay` accepts `overlay: 1.0.x` and `overlay: 1.1.x`.

> [!NOTE]
> The Overlay Specification is defined for OpenAPI documents. Applying an overlay to an AsyncAPI or Arazzo document is
> an extension of this project, not behavior sanctioned by the specification. The OpenAPI Initiative closed
> [Overlay-Specification#268](https://github.com/OAI/Overlay-Specification/issues/268) as "not planned", and we filed
> [#367](https://github.com/OAI/Overlay-Specification/issues/367) to revisit it. See the
> [Overlay overview](overlay/overview.md) for how targeting works.
